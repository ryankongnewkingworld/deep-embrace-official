# 本地打开深拥智能官网

这是当前 Mac 上的完整网站预览，不依赖官网域名能否打开，适合现场展示与检查。

1. 打开项目文件夹 `deep-embrace-official`。
2. 双击 **打开深拥智能官网.command**。
3. 等待浏览器自动打开 `http://localhost:4174/`。
4. 展示期间保留弹出的终端窗口；结束时在该窗口按 **Control + C**。

如果浏览器没有自动打开，可以手动输入上面的本地地址。

此地址仅供这台 Mac 使用，发给别人或在手机上打开不会连接到此网站。它不会改变线上网站的访问权限。

页面、案例视频和专家介绍均来自本机项目。咨询信息写入本地数据库，与线上客户记录分开；目前飞书和 DeepSeek 尚未接通时，不会显示成已成功调用。请勿在演示中填写真实客户资料。

启动文件需要与项目、依赖和构建文件放在一起，请勿单独移走。它会复用已运行的同一预览，不会关闭占用端口的其他程序。

启动器将运行时配置保存在项目自己的 `.sites-runtime` 目录中，不改动系统偏好设置。网页只监听本机回环地址，不对局域网或互联网开放。
