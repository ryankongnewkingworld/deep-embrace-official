# 企业 AI 转型成熟度与机会评估

官网入口为 `/assessment`，顶部导航应以新标签页打开。题库与规则来自用户提供的首版源码，版本保留 `2.1.0-web`。

## 已实现

- A/B/C/D 分组各 3/3/3/4 题；每组全部作答后才能继续，可返回修改。P01–P04 是独立的选填补充，各 1500 字，不计分。
- 原题库、确定性评分与解读全部保留。Q08 独立为净收益状态；未知项显示范围；Q01–Q03 不适用时不显示总体指数。前台只突出三个维度，不提供行业排名。
- 无需联系方式即可查看结果、判断依据、候选机会、人机分工、验证指标、边界及四周行动建议。
- 六项联系方式由 `/api/leads` 服务端验证、实际保存后，才签发正式报告读取凭证。提交咨询不等于时间已确认。
- `/api/assessment/report` 通过真实已保存线索和随机令牌授权，再由服务器重新计算评分。报告下载为完整 HTML，可浏览器打印或保存 PDF。没有伪装成服务端 PDF 导出。
- 正式报告所有用户文本均 HTML 转义，不含联系方式。不信任客户端上传的评分。AI 解读须通过原评估 API 的 HMAC 签名验证，才能进入正式报告，否则使用重新计算的规则解读。
- 核心答案与进度仅在当前浏览器会话内缓存，24 小时后不恢复；联系方式由共用预约表单处理，不写问卷会话缓存。

## 当前联通边界

未配置 `DEEPSEEK_API_KEY` 时，结果明确标注“规则初评”，不会调用模型。所有规则功能可正常体验。飞书通知由共用预约服务处理，未配置不能宣称已经通知。

原交付的 Python/FastAPI、单实例 SQLite、持久后台任务不能直接运行在本官网的 Cloudflare Workers 上。本版采用 Workers 原生适配器：确定性评估即时返回；配置模型后执行最长 50 秒的有界请求，失败或超时返回完整规则解读，并在前台明确说明。**没有宣称实现原 Python 版本的跨进程恢复后台模型队列。** 需要长时模型任务时，应另接持久任务队列或部署原独立评估服务。

## 服务端环境变量

| 变量 | 用途 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 可选，启用实际 DeepSeek 辅助解读；仅服务端读取 |
| `DEEPSEEK_MODEL` | 可选，默认 `deepseek-v4-pro`；须用实际账户验证权限、配额与响应时间 |
| `LEAD_HASH_SECRET` | 与预约服务共享的服务端随机密钥，HMAC 用不同用途前缀隔离；缺省时用预约加密密钥 |
| `LEAD_ENCRYPTION_KEY` | 预约服务的加密密钥；报告访问依赖实际保存的预约记录 |

DeepSeek 请求仅包含选项、经基础手机号/邮箱/证件号遮盖的 P 项与固定评分；不发送六项联系人资料。基础遮盖不代表全面识别商业秘密。只读取最终 `content`，不保存或展示 `reasoning_content`。所有 AI 结果通过严格结构、长度与题号校验，未知证据不能独立支撑“优势”。语义质量仍须实际抽检。

## API

- `GET /api/assessment`：返回 `modelEnabled`、`rulesVersion`，不泄露密钥。
- `POST /api/assessment`：`{scope, answers, opportunities, analysisConsent:true, website:''}`。核心题必须完整、选项须来自题库；返回评估与可选签名。
- `POST /api/leads`：共用预约接口；携带完整 `assessment`，接受后返回 `id` 和 `reportToken`。
- `POST /api/assessment/report`：`{leadId, reportToken}`，凭证不放查询字符串；返回不缓存的 HTML 报告。错误或未经提交的凭证不能获取报告。

正式报告重新计算评分，签名完整有效时保留 DeepSeek 解读；篡改答案、结果或签名均不会使伪造 AI 结论进入正式报告。
