# 深拥智能官方网站

移动端优先的官网、案例详情、AI应用案例库、成熟度评估与业务咨询。

## 页面

- `/` 品牌首屏、企业难题、服务、案例、技术栈、方法论、差异化、使命与11位专家、企业标识、评估入口及咨询表单。
- `/cases` 可搜索和筛选的AI应用案例库。
- `/cases/brand-chain` 品牌连锁案例，含数字人、视频生产与组织应用材料。
- `/cases/professional-services` 律政AI模拟方案，明确区分场景研究与真实交付。
- `/cases/cross-border` AI达人业务与产品化，含视频、系统演示及产品材料。
- `/assessment` 原13题成熟度评估、选填业务场景、三维评分、独立净收益状态、报告与咨询。
- `/privacy` 信息使用说明。
- `/admin` 受管理员令牌保护的咨询管理、导出、通知重试、删除。

## 内容维护

- 主站：`app/page.tsx`、`app/globals.css`。
- 专家资料：`data/experts.ts`。萧逸云与许恒分别配置，可独立替换。
- 重点案例：`data/cases.ts`；更多案例：`data/case-library.ts`。
- 素材清单：`public/media/manifest.json`，包含尺寸、视频时长、原文件名。
- 所有视频经H264/AAC兼容性转换，完整保留时长，点击后才加载；单文件均低于25MiB。
- 头像使用真实照片，按人CSS取景。原始Logo保持形状，以SVG视窗裁切显示。

## 本地开发

Node22.13+。依赖由Sites标准安装流程准备。

```sh
CHOKIDAR_USEPOLLING=true npm run dev -- --host 127.0.0.1
```

本地端口默认5173。该环境文件监测需要轮询。构建遵循Sites技能标准流程。D1迁移位于`drizzle/`；不可重复应用已执行的迁移。

## 集成状态

已实现并验证：表单校验、AES-GCM加密D1存储、重复提交处理、管理端授权、规则评估、正式报告授权与生成。

已提供接口但需真实凭据：

- 飞书通知：`FEISHU_WEBHOOK_URL`，可选签名密钥`FEISHU_WEBHOOK_SECRET`。
- DeepSeek辅助解读：`DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`。未配置时明确使用固定规则初评，不伪装成模型结果。
- 管理端需要`ADMIN_TOKEN`。已生成的部署密钥存于平台秘密配置；本地测试配置只在忽略的`.dev.vars`，不得提交Git或发至公开页面。

详见`docs/integrations.md`与`docs/assessment-integration.md`。

网站默认私密预览；公开访问或自有域名需相应发布与域名配置。浏览器隐藏视频下载入口和禁用右键只能降低随手保存，不能阻止抓包、录屏或所有浏览器的另存功能。
